# Weather Analysis Dashboard 🌦️📊

An interactive, multi-page data analytics dashboard that provides deep historical insights and 10-year future forecasting for key climate metrics across southern Indian states (**Andhra Pradesh, Karnataka, Kerala, Tamil Nadu, and Telangana**). This project highlights trends, anomalies, and patterns in **Rainfall, Temperature, and Humidity** over multi-year periods.

---

## 🚀 Features & Dashboards

The project is structured into three dedicated core analytics modules, accessible via an intuitive navigation menu:

### 1. Rain Fall Analysis Dashboard 🌧️
* **Accumulated Volume Tracking:** Monitors total accumulated rainfall ($33.09\text{K}$) and tracks overall monthly averages ($137.87$).
* **Categorical Breakdown:** Segregates rainy days into *Light Rain* (36.25%), *Moderate Rain* (35.83%), *Heavy Rain* (22.08%), and *No Rain* (5.83%).
* **Regional & Temporal Trends:** Identifies July as the peak precipitation month ($7.0\text{K}$) and maps state-by-state variations using stacked bar distributions.
* **Predictive Insights:** Features a **10-Year Future Forecast** module modeling expected rainfall pathing up to 2036.

### 2. Temperature Analysis Dashboard 🌡️
* **Key Metric Cards:** Highlighting a historical Average Temperature of $26.92^\circ\text{C}$, Peak Heat Wave of $45.90^\circ\text{C}$, and Minimum Temperature of $11.10^\circ\text{C}$.
* **Climate Profiles:** Evaluates the overall seasonal distribution categorizing weather into *Warm* (47.92%), *Mild* (40.42%), and *Extreme Heat* (11.67%).
* **Historical Mapping:** Displays monthly maximum bounds alongside structured breakdowns of state-level temperature dynamics from 2022 onwards.

### 3. Humidity Analysis Dashboard 💧
* **Atmospheric Saturation:** Monitors an Average Humidity of $16.80\text{K}$ index units with a Peak Saturation Record of $95.45$.
* **Comfort Levels:** Evaluates ambient comfort thresholds, identifying *Pleasant* (52.08%), *Very Humid* (25.00%), and *Dry* (22.92%) environments.
* **Chronological Inversions:** Tracks month-over-month averages showing peak humidity values dipping into seasonal lows down to $56\%$ by February.

## 🛠️ Tech Stack & Tools

* **Data Visualization & Dashboarding:** Power BI / Tableau (or equivalent BI reporting tool)
* **Data Sources:** Multi-year meteorological datasets spanning South Indian regional monitoring stations.
* **Forecasting Engine:** Time-series forecasting algorithms (such as ARIMA or Exponential Smoothing) mapped over a 10-year horizon.

---

## 📈 Key Insights Extracted

* **Monsoon Dominance:** July heavily dominates the regional water cycle across all states, while February registers as the driest month overall.
* **State-by-State Divergence:** Kerala historically accounts for the largest proportion of heavy rain distribution within the collective data pool.
* **Predictive Climate Inversion:** Long-term modeling shows subtle cyclical contractions in overall rainfall volumes paired with stabilizing apparent humidity parameters over the next decade.
